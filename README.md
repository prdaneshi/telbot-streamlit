# 🤖 ربات تلگرام + پنل مدیریت Streamlit

یک ربات تلگرام ساده (پاسخ به /start، دکمه‌های شیشه‌ای، پاسخ به متن)
همراه با یک پنل مدیریت کامل ساخته‌شده با Streamlit.

## ساختار پروژه

| فایل | نقش |
|---|---|
| `bot.py` | ربات تلگرام (python-telegram-bot) — به صورت مستقل اجرا می‌شود |
| `app.py` | پنل مدیریت (Streamlit) |
| `database.py` | دیتابیس SQLite مشترک (کاربران و پیام‌ها) |
| `config.py` | خواندن/ذخیره توکن و تنظیمات |

## راه‌اندازی

### ۱. نصب وابستگی‌ها

```powershell
pip install -r requirements.txt
```

### ۲. دریافت توکن

در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید، با `/newbot`
یک ربات بسازید و توکن را بردارید. سپس:

```powershell
Copy-Item .env.example .env
# فایل .env را باز کنید و توکن را جایگزین کنید
```

(یا فقط پنل را باز کنید و توکن را در سایدبار وارد و ذخیره کنید.)

### ۳. اجرا

**پنل مدیریت** (پیشنهادی — از داخل خود پنل هم می‌توانید ربات را روشن/خاموش کنید):

```powershell
streamlit run app.py
```

**یا اجرای مستقیم ربات:**

```powershell
python bot.py
```

## امکانات پنل

- ▶️ / ⏹ روشن و خاموش کردن ربات از داخل مرورگر + دیدن لاگ
- 📊 آمار: تعداد کاربران، پیام‌های دریافتی/ارسالی، پیام‌های امروز
- 👥 لیست کاربران
- 💬 آخرین پیام‌های رد و بدل شده
- 📨 ارسال پیام به یک کاربر یا ارسال انبوه به همه

## نکته‌ها

- دیتابیس SQLite (`bot_data.db`) با حالت WAL بین دو پروسه (ربات و پنل) مشترک است.
- اگر پنل را ببندید، ربات که از پنل روشن شده همچنان در پس‌زمینه اجرا می‌ماند؛
  برای توقف حتماً از دکمه «توقف» در پنل استفاده کنید.
